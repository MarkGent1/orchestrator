# 2.5 Phase 2 — Logging & observability

This is essential for debugging and trust.

### Per-agent logs:

*   context packet    
*   model used    
*   output    
*   retries    
*   errors    
*   fixloop attempts    
*   validation results    
*   architecture violations    

### Supervisor logs:

*   decisions    
*   routing    
*   state transitions    
*   resume points    
*   PR creation    
*   branch creation    

### Metrics:

*   latency per agent    
*   cost per agent    
*   error rate per agent    
*   retry count    
*   fixloop count    
*   validation failures    

### Timeline:

A chronological record of:

*   planning    
*   decomposition    
*   execution    
*   fixloops    
*   validation    
*   PR creation
    
This becomes your **agentic observability dashboard**.
